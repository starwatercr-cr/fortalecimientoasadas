Preguntas frecuentes

¿Qué significa tricapa?

El tanque combina una capa exterior con protección UV, una capa intermedia negra y un interior blanco para facilitar la inspección visual del agua.

¿Se puede enterrar?

No. Este modelo está diseñado para instalarse sobre una superficie firme y nivelada. Para una instalación subterránea se requiere una cisterna diseñada para ese uso.

¿Sirve para captar agua de lluvia?

Sí, con un filtro de entrada que retenga hojas y sólidos. Si el agua tendrá uso doméstico o de consumo, evalúe además el tratamiento y los controles adecuados.

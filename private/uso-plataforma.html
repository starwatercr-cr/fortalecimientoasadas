Cómo interpretar estos datos

El conteo se pausa cuando la pestaña está oculta o pasan dos minutos sin interacción. Se controla la superposición entre pestañas y dispositivos de una misma cuenta para reducir duplicaciones.

Una apertura corresponde a una herramienta visitada, no a un inicio de sesión. El tiempo es una estimación de uso y no una medida del desempeño de la persona. Puede ser menor al real si falla la conexión o se cierra el navegador. No se registran documentos, contenidos de formularios ni las teclas que se escriben. Los datos empiezan a recopilarse cuando se publica esta actualización; no se reconstruye el uso anterior.
